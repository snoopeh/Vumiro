# Product

Vumiro makes adding friends a request/accept flow with automatically filled names. An optional online username can be looked up; a public contact code remains the fallback when no username is available or the person is offline. New requests appear inside the app with accept/decline controls and background attention.

Rooms shows open/live rooms of mutual friends. Status refreshes on room events, opening Rooms, going online and reconnecting. Users can request entry; the owner approves. Disconnected users have a reconnect button. Chat stays in the room, with no cloud message history.

Profiles support pictures. Stream FPS, resolution, bitrate and content preference are configurable inside and outside the room. Double-clicking a stream toggles fullscreen. The window uses the supplied black/red identity, ribbon-V icon, and a compact dark custom title bar with standard window controls.
