# Product

Friends need one repository download followed by an update button, without files being sent manually. Updates must preserve their device identity and contact book. New versions must be discoverable inside the application, with installation occurring only when the user chooses it.

Only mutually added friends should see online status or place calls. A leaked invitation must not allow a stranger into a screen-sharing room. A room owner can admit their mutual friends; group participants are visible to everyone in that room.

Existing profile settings accommodate an Updates panel. Existing room controls accommodate private-room guidance. Runtime acceptance is the user's responsibility per their explicit request.
