# Vumiro 1.17.0

- Drag and zoom a new profile picture before saving its crop.
- Show a crossed-out microphone when muted and use consistent settings and invite icons.
- Show a red startup spinner, then remove its overlay and repaint the app immediately when loading completes.
- Open participant profiles from the People tab and send verified friend requests.
- Return home from the sidebar logo and browse the app while the room stays connected, with a persistent return-to-room control.
- Show People-list scrolling only when the participants exceed the available height; keep rows within the pane width.

The avatar editor is included in the existing friends script so the package remains compatible with the file allowlist in earlier Vumiro updaters.

Compilation and packaging only. Runtime and visual testing remain with the user as requested.
