# Vumiro 1.18.0

Closing Vumiro's window now hides it in the Windows system tray instead of quitting. Rooms, microphone, screen sharing and online presence stay connected.

Double-click the tray icon, or choose **Open Vumiro** from its menu, to restore the window. Choose **Quit Vumiro** to exit completely. The regular minimize button retains its taskbar behavior. Application updates and Windows shutdown bypass close-to-tray so they can finish normally.

Compilation and packaging only. Runtime and visual testing remain with the user as requested.
